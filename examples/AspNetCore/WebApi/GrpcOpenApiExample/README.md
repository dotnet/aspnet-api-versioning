# ASP.NET Core gRPC OpenAPI Example

This example project illustrates using ASP.NET Core with transcoded [gRPC] APIs, [OpenAPI], and [Scalar]. Launch the
project and try the example requests to view an API in action.

[gRPC]: https://github.com/grpc/grpc-dotnet
[OpenAPI]: https://www.openapis.org/
[Scalar]: https://scalar.com/
