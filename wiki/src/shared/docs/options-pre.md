# API Explorer Options

The API Explorer options allows you to configure, customize, and extend the default behaviors when you add API
exploration support. The configuration options are specified by providing a callback to the appropriate extension
method:

The `ApiExplorerOptions` have the following configuration settings:

- [GroupNameFormat](#group-name-format)
- [SubstituteApiVersionInUrl](#substitute-api-version-in-url)
- [SubstitutionFormat](#substitution-format)
- [DefaultApiVersion](#default-api-version)
- [DefaultApiVersionParameterDescription](#default-api-version-parameter-description)
- [AssumeDefaultVersionWhenUnspecified](#assume-default-version-when-unspecified)
- [ApiVersionParameterSource](#api-version-parameter-source)
- [AddApiVersionParametersWhenVersionNeutral](#add-api-version-parameters-when-version-neutral)
- [RouteConstraintName](#route-constraint-name)
